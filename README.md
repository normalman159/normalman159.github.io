## About Me

I am **Tran Phuoc Thanh Nhan**, a **Bachelor of Computer Science** student at the **University of Information Technology, Vietnam National University Ho Chi Minh City (UIT VNU-HCM)**. My work focuses on **Natural Language Processing**, **Generative AI**, **Retrieval-Augmented Generation**, and **Multi-Agent Systems**.

I am also an **Undergraduate Research Assistant** under the supervision of **Dr. Dang Van Thin**, working on Transformer-based model fine-tuning, LLM fine-tuning with LoRA, RAG pipelines, and autonomous agentic workflows for NLP tasks.

## Local Development

This website is built with **Jekyll** and the **al-folio** starter theme.

```bash
# Install Ruby dependencies
bundle install

# Serve the site locally
bundle exec jekyll serve --baseurl ""

# Build the site
bundle exec jekyll build --baseurl ""
```
